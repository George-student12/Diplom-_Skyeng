# Проект автоматизации тестирования интернет-магазина «Читай-город»

Этот репозиторий содержит автоматизированные UI- и API-тесты для интернет-магазина **[Читай-город](https://www.chitai-gorod.ru/)**.  
Тесты написаны на Python с использованием `pytest`, `Selenium WebDriver` (UI) и библиотеки `requests` (API).  
Для создания наглядных отчётов используется **Allure Framework**.

---

## 1. Описание проекта

- **UI-тесты** (файл `test_ui.py`) проверяют сценарии поиска товаров, работы с корзиной и навигации по каталогу через реальный браузер.  
  Используется Page Object Model - страницы и элементы вынесены в отдельные классы (`ui_page.py`).
- **API-тесты** (файл `test_api.py`) отправляют прямые HTTP-запросы к эндпоинтам корзины и валидируют коды ответов и логику API.
- **Общая конфигурация** размещена в `conftest.py`: загрузка переменных окружения, определение HTTP-заголовков и фикстура WebDriver.

## 2. Установка зависимостей

**Что это значит**  
Установка зависимостей - это процесс загрузки всех сторонних библиотек, перечисленных в `requirements.txt`, без которых проект не запустится.  
Команда `pip install -r requirements.txt` прочитает этот файл и установит каждую библиотеку нужной версии.

Содержимое папки requirements.txt:
selenium~=4.43.0
requests~=2.33.1
pytest~=9.0.3
dotenv~=0.9.9
python-dotenv~=1.2.2
allure-python-commons~=2.15.3

**Пошаговая инструкция**
1. Убедитесь, что у вас установлен **Python 3.11+** и менеджер пакетов `pip`.
2. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <https://github.com/George-student12/Diplom-_Skyeng.git>
   cd <Diplom-_Skyeng>

## 3. Настройка окружения

1. Создайте в корне проекта файл .env
2. Запишите в него следующие переменные (подставьте свои значения):
 BASE_URL=https://web-agr.chitai-gorod.ru/web/api
 AUTHORIZATION=ваш токен авторизации

## 4. Запуск тестов

1. Всех тестов: pytest
2. API тестов: pytest test_api.py 
3. UI тестов: pytest test_ui.py

## 5. Генерация отчётов Allure

1. Запуск теста Allure с сохранением данных в папке allure-results:
pytest --alluredir=allure-results -v
2. Сгенерируйте и откройте HTML-отчёт:
allure serve allure-results
